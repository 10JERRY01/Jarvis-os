INSTALL & OPERATIONS GUIDE

Getting Started with Jarvis OS v1.0

1. Flash the ISO to a USB Drive

Download the hybrid ISO from the homepage (via Cloudflare R2 or GitHub Releases) and verify its checksum before flashing with BalenaEtcher, Rufus (DD mode), or Ventoy.

sha256sum -c SHA256SUMS.txt
# On Linux:
sudo dd if=jarvis-os-debootstrap-amd64.hybrid.iso of=/dev/sdX bs=4M status=progress oflag=sync

2. Install Local Bonsai 27B Weights

To keep the bootable ISO lean (~2.4 GB), multi-gigabyte neural weights are hydrated after installation with a single script:

bash /opt/jarvis-core/tools/setup_models.sh /path/to/Bonsai-27B-GGUF

3. Dual-Environment & Terminal Commands

jarvis mode desktop             # Switch to Apple Cupertino / Minimalist mode (frees VRAM)
jarvis mode jarvis              # Resume Jarvis 3D Ambient Core
jarvis theme cupertino-light    # Switch between Cupertino Dark/Light, Zen, Nordic, Cyber
sudo nala install obs-studio    # Install Debian packages cleanly
?? find files larger than 100MB # AI natural-language bash helper
