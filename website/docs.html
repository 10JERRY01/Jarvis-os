INSTALL & OPERATIONS GUIDE

Getting Started with Jarvis OS v1.0

1. Download & Flash the 1.58 GiB Hybrid ISO

Download directly from Internet Archive (or GitHub Releases) and verify its SHA-256 checksum before flashing with BalenaEtcher, Rufus (DD mode), or Ventoy.

sha256sum -c SHA256SUMS.txt
# Expected: c4ae2351dc1abecf1cba1ec078074500fbcb073c0f792e2788b4f6e659d0278a

# On Linux:
sudo dd if=jarvis-os-debootstrap-amd64.hybrid.iso of=/dev/sdX bs=4M status=progress oflag=sync

2. Install Local Bonsai 27B Weights

To keep the bootable ISO compact at 1.58 GiB, multi-gigabyte neural weights are hydrated after installation with a single script:

bash /opt/jarvis-core/tools/setup_models.sh /path/to/Bonsai-27B-GGUF

3. Dual-Environment, Apple Themes & Software Commands

jarvis mode desktop             # Switch to Apple Cupertino / Minimalist mode (frees VRAM)
jarvis mode jarvis              # Resume Jarvis 3D Ambient Core
jarvis theme cupertino-dark     # Apple Cupertino Dark (left traffic lights)
jarvis theme cupertino-light    # Apple Cupertino Light
jarvis theme zen                # Minimalist Pop!_OS / Ubuntu Slate
jarvis theme nordic             # Nordic Arctic Frost
sudo nala install obs-studio    # Fast Debian package installation
?? find files larger than 100MB # AI natural-language bash helper

4. Live Default Credentials & Shortcuts

Live session auto-logins as jarvis (password: jarvis with passwordless sudo). Launch the 3D HUD with Super + Space, toggle between Jarvis Core and Desktop with Meta + Shift + M, or inspect screen content with Meta + Shift + S.
